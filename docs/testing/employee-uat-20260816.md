# Eighty ERP 직원 1차 UAT — 2026-08-16

## 목적
직원에게 전체 기능을 무작정 테스트시키지 않고, 실제 업무의 핵심 흐름만 먼저 검증한다.

- 테스트 대상: ERP 고객 / 일정 / 직원 할 일 / 견적 / Employee Master
- 제외: EIGHTY WINDOW LAB의 현장점검, 사진진단, AI 판정, 고객 점검리포트
- WINDOW LAB 기능을 ERP에 중복 구현하지 않는다.

## 테스트 준비 상태
- 활성 Employee Master: 13명
- 로그인 준비 완료: 9명
- 기존 Master는 있으나 로그인 계정 미연결: 4명
  - 조근아
  - 김정아
  - 오용철
  - 이응준
- 비활성 로그인 계정: 0명
- 승인 대기: 0명

1차 UAT는 로그인 준비 완료 9명으로 진행하고, 미연결 4명은 기존 Master에 가입 계정을 안전하게 연결한 후 2차로 확대한다.

> 기존 Master가 있는 직원에게 신규 입사자용 초대 링크로 새 Employee Master를 만들지 않는다.

## 테스트 원칙
1. 실제 고객에게 문자/카카오톡을 보내는 단계는 별도 승인 전 테스트하지 않는다.
2. 삭제 테스트는 물리 삭제가 아니라 보관/복원만 사용한다.
3. 테스트용 고객/견적에는 제목 또는 메모에 `UAT`를 넣어 구분한다.
4. 오류가 나면 반복 클릭하지 말고 화면 캡처 + 마지막 동작을 기록한다.
5. 오류 보고는 아래 5가지 중 하나로 분류한다.
   - 오류
   - 사용하기 어려움
   - 느림
   - 헷갈리는 표현
   - 필요 기능

## UAT 시나리오

### UAT-01 로그인 / 대시보드
- ERP 로그인
- 대시보드 진입
- 본인 이름/권한이 정상인지 확인
- 대표·관리자: 경영 대시보드와 오늘 할 일이 함께 보이는지 확인
- 일반 직원: 본인 목표/오늘 할 일이 보이는지 확인

완료 기준: 오류 메시지 없이 대시보드가 열리고 권한에 맞는 정보가 표시된다.

### UAT-02 고객 목록 / 검색 / 상세
- 고객관리 진입
- 고객 목록 표시 확인
- 이름 또는 연락처로 검색
- 고객 상세 열기
- 담당자/상태/상담정보 확인

완료 기준: 목록, 검색, 상세가 끊기지 않고 현재 회사 데이터만 보인다.

### UAT-03 신규 고객 / 수정
- 테스트 고객 1건 등록 (`UAT` 표기)
- 담당 직원 지정
- 상담 상태 또는 메모 수정
- 저장 후 다시 열어 값 확인

완료 기준: 저장한 값이 재조회 시 동일하다.

### UAT-04 일정
- UAT 고객에 상담 또는 후속 일정 등록
- 본인 일정 목록에서 확인
- 일정 수정 후 재확인

완료 기준: 담당자와 시간이 정확히 표시된다.

### UAT-05 직원 할 일
일반 직원:
- 본인 할 일 1건 생성
- 진행중 변경
- 완료 처리

manager:
- 본인 또는 팀원에게 할 일 지정
- 팀 범위 외 직원 지정이 허용되지 않는지 확인

대표/관리자:
- 직원에게 할 일 지정
- 완료 상태 확인

완료 기준: 권한 범위 안에서는 저장되고, 범위 밖 작업은 차단된다.

### UAT-06 창호 견적
- UAT 고객 선택
- 창호 견적 작성
- 항목 2~3개 입력
- 특별할인 확인
- 저장
- 견적 목록에서 다시 열기
- PDF 확인

확인 항목:
- 공급가
- 부가세
- 할인
- 합계
- 유리사양/규격 중복 여부
- 표준시공비 표현
- PDF와 화면의 금액 일치

### UAT-07 인테리어 Excel 견적
- 기존 UAT 고객 선택
- 담당자 선택
- Excel 1개 업로드
- 인식 결과/오류 표시 확인
- 공급가/부가세/총액 확인
- 정식 견적으로 저장
- 생성된 견적 상세 열기
- 원본 Excel 연결 확인

재시도 테스트:
- 저장 중에는 버튼이 중복 클릭되지 않는지 확인
- 저장 오류가 발생할 경우 같은 화면에서 다시 저장해도 견적이 중복 생성되지 않는지 확인

완료 기준: 견적 1건 + 해당 원본 Excel 1건이 연결된다.

### UAT-08 직원 Master — 대표/관리자만
- 활성 직원 목록 확인
- 이름 + 팀 + 직급 표시 확인
- 병합/보관 직원 보기 확인
- 테스트 대상으로 승인된 직원 1명만 보관
- 보관 목록에서 확인
- 다시 복원

금지:
- 대표 본인 보관
- owner/director/admin 계정을 임의로 보관
- 담당 업무가 남은 직원을 이전 없이 보관

완료 기준: 기존 고객/견적/일정 이력을 지우지 않고 직원 상태만 보관/복원된다.

## P0 / P1 분류
### P0 — 즉시 수정
- 로그인 불가
- 고객 등록/조회 불가
- 견적 저장 불가 또는 금액 오류
- Excel 업로드 중복/유실
- 다른 회사 데이터 노출
- 권한 우회
- 데이터 삭제/손실
- 핵심 화면 반복 오류

### P1 — 직원 테스트와 병행 개선
- 가독성
- 버튼 위치
- 문구
- 모바일 레이아웃
- 로딩 체감
- 목록 필터/검색 편의
- 추가 자동화

## 직원 테스트 종료 기준
- 핵심 시나리오 P0 오류 0건
- 고객 등록/조회 정상
- 일정 정상
- 직원 업무 정상
- 창호/인테리어 견적 정상
- PDF 정상

- 권한/회사 격리 정상
- 남은 문제는 P1 목록으로 분리 가능
