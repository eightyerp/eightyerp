# 에잇티 ERP 재무·손익·직원정산 지표 정의서 v1

- 상태: Gate 2 설계안
- 적용 전제: 운영 DB 미적용
- 목적: 화면·SQL·ERP 자동분석·AI 심층분석이 같은 용어와 계산식을 사용하도록 기준을 고정한다.

## 1. 지표 사용 원칙

1. 매출, 수금, 현금흐름, 손익은 서로 다른 지표다.
2. 현장 기여마진과 내부 손익 매출총이익을 같은 의미로 사용하지 않는다.
3. 직원 예상 정산금과 확정 정산금, 지급완료 금액을 분리한다.
4. 공식값, 잠정값, Excel 이관값, 참고용 가배분값을 화면에서 구분한다.
5. 각 핵심 수치에는 기준기간·자료출처·최종 업데이트일·입력완전성을 표시한다.
6. 회사공통비는 공식 사업부 손익에 임의 배분하지 않는다.

## 2. 매출·수금 지표

### 2.1 영업실적 매출

**정의**

현장·시공·담당직원 실적원장 기준 매출이다.

**사용처**

- 직원별 연간 8억원 목표 달성률
- 직원별 매출 점유율
- 직원 영업성과
- 창호팀 잠정 정산의 임시 대체값

**금지사항**

- 실제 수금액으로 해석하지 않는다.
- 내부 손익 매출과 강제로 맞추지 않는다.

### 2.2 내부 손익 매출

**정의**

회사 내부 손익계산서의 월별 매출 인식 기준 매출이다.

**사용처**

- 회사·사업부 손익
- 매출총이익률
- 영업이익률
- 최종 순이익률

### 2.3 수금액

**정의**

고객에게 실제로 받은 금액 중 관리자 확정 또는 정식 기초잔액으로 반영된 금액이다.

```text
누적 수금액
= 기초 수금잔액
+ 확정된 실제 수금
- 취소·환불된 수금
```

**사용처**

- 계약별 기수금
- 미수금
- 현금유입
- 입금예정 관리

### 2.4 미수금

```text
미수금
= 계약금액
- 기초 수금잔액
- 확정된 실제 수금
+ 확정된 환불·취소금액
```

미수금은 0원 미만이 될 수 없다. 초과수금은 별도 경고로 관리한다.

### 2.5 수금계획 달성률

```text
회차별 수금계획 달성률
= 해당 회차 배분수금액 / 해당 회차 예정금액 × 100
```

## 3. 원가·손익 지표

### 3.1 현장 직접원가

현장과 직접 연결되고 관리자 승인 및 회계분류가 완료된 비용이다.

포함 예:

- 자재비
- 외주비
- 현장 인건비
- 철거·양중·운반
- 현장 추가비용
- 정산 전 반영된 사후지출

제외 예:

- 대표급여
- 경영팀 급여
- 사무실 임차료
- 회사공통 광고비
- 회계·노무·법무비

### 3.2 현장 기여마진

```text
현장 기여마진
= VAT 제외 현장 영업실적 매출
- 승인·반영된 현장 직접원가
```

**사용처**

- 현장 수익성
- 담당직원 실적
- 인테리어팀 예상 정산

### 3.3 내부 손익 직접원가

내부 손익 원장의 사업부 직접원가다. 현장실적 원가와 포함범위·인식월이 다를 수 있다.

### 3.4 내부 손익 매출총이익

```text
사업부 매출총이익
= 사업부 내부 손익 매출
- 사업부 내부 손익 직접원가
```

### 3.5 사업부 판관비

해당 사업부에 직접 귀속되는 판매관리비다.

- 창호팀 급여
- 창호 전용 광고비
- 창호 전용 차량비
- 인테리어팀 급여
- 설계프로그램
- 인테리어 전용 광고비

### 3.6 회사공통 판관비

사업부에 직접 귀속시키기 어려운 본사성 비용이다.

- 대표급여
- 경영팀 급여
- 사무실 임차료
- 공통 전산비
- 회계·노무·법무비
- 회사 전체 광고비
- 공통 보험료

### 3.7 사업부 영업손익

```text
창호 영업손익
= 창호 매출총이익 - 창호 실제 판관비

인테리어 영업손익
= 인테리어 매출총이익 - 인테리어 실제 판관비
```

회사공통비를 차감하기 전 사업부 직접 손익이다.

### 3.8 회사 영업이익

```text
회사 영업이익
= 창호 영업손익
+ 인테리어 영업손익
- 회사공통 판관비
```

### 3.9 최종 순이익

```text
최종 순이익
= 회사 영업이익
+ 장려금
+ 기타수익
- 영업외비용
- 세금·금융비용
- 기타조정
```

### 3.10 참고용 가배분 손익

회사공통비를 매출비중·인원수·직접원가비중·사용자 지정비율로 나눈 참고 시나리오다.

화면에는 반드시 다음 문구를 표시한다.

> 참고용 가배분이며 공식 사업부 손익이 아닙니다.

## 4. 지출 상태 지표

### 4.1 승인상태

- `pending`: 관리자 검토대기
- `approved`: 승인완료
- `rejected`: 반려
- `cancelled`: 취소

### 4.2 지급상태

- `unpaid`: 회사 지급 전
- `paid`: 이미 지급됨
- `partially_refunded`: 일부 환불
- `refunded`: 전액 환불

### 4.3 증빙상태

- `missing`: 미첨부
- `attached`: 첨부됨
- `tax_reviewed`: 세무구분 확인
- `complete`: 증빙처리 완료

### 4.4 회계상태

- `unclassified`: 사업부·비용성격 미분류
- `review_required`: 검토 필요
- `ready`: 반영 가능
- `posted`: 손익 반영
- `closed`: 월마감 완료

### 4.5 손익 반영 가능 비용

```text
approval_status = approved
AND business_unit <> unclassified
AND cost_nature <> other 또는 관리자 확정
AND accounting_status in (ready, posted, closed)
```

## 5. 직원 목표·정산 지표

### 5.1 직원 연간 매출목표

기본값은 직원당 연간 8억원이다.

```text
목표 달성률
= 직원 영업실적 매출 / 직원 연간목표 × 100
```

공동매출은 별도 배분승인 없이 직원 개인 목표에 포함하지 않는다.

### 5.2 인테리어팀 잠정 예상 기본정산금

```text
잠정 예상 기본정산금
= FLOOR(MAX(현장 최종 기여마진 합계, 0) × 50%)
```

현재 Excel 이관 단계에서는 직원별 집계마진을 잠정 대체값으로 사용할 수 있으나 다음 배지를 표시한다.

> Excel 이관 실적 기준 잠정값 · 실제 지급액 아님

### 5.3 창호팀 잠정 예상 기본정산금

공식 기준:

```text
잠정 예상 기본정산금
= FLOOR(담당 확정 계약금액 합계 × 2%)
```

현재 실제 ERP 계약이 없는 기간에는 직원별 영업실적 매출을 임시 대체값으로 사용하고 다음 배지를 표시한다.

> 영업실적 매출 대체계산 · 실제 계약 연동 전

### 5.4 예상 지급액

```text
예상 지급액
= 잠정 예상 기본정산금
+ 추가 인센티브
- 승인된 차감액
- 기지급액
```

0원 미만으로 표시하지 않는다. 초과 차감은 다음 정산 이월 또는 별도 채권으로 관리한다.

### 5.5 확정 정산금

관리자가 현장 원가·사후지출·증빙·추가인센티브·차감을 검토하고 승인한 스냅샷 금액이다.

예상값이 바뀌어도 확정 정산금을 자동 수정하지 않는다.

### 5.6 지급완료 금액

직원에게 실제 지급 처리된 금액이다.

### 5.7 미지급 정산금

```text
미지급 정산금
= 확정 정산금 + 확정 추가인센티브 - 확정 차감액 - 지급완료 금액
```

## 6. 데이터 상태

### 출처상태

- `erp`: ERP 자동자료
- `manual`: 관리자 수기
- `excel_import`: Excel 이관
- `opening_balance`: 기초잔액

### 값의 확정상태

- `official`: 공식 확정
- `provisional`: 잠정
- `estimated`: 예상
- `allocated_reference`: 참고용 가배분
- `incomplete`: 일부 입력

### 데이터 신뢰도

- `high`: ERP 자동 또는 마감·승인 완료
- `medium`: 관리자 수기, 대조 완료
- `low`: Excel 이관, 일부 대조
- `incomplete`: 미입력·부분입력
- `review_required`: 충돌·미분류·검토 필요

## 7. 화면 표시 필수 메타정보

핵심 카드·AI 분석·Excel 출력에는 가능하면 다음을 함께 표시한다.

- 지표명
- 기준기간
- 기준월
- 데이터 출처
- 값의 확정상태
- 최종 업데이트일
- 일부 입력 여부
- 회사공통비 포함 여부
- 참고용 가배분 여부

## 8. AI 분석 표현규칙

금지:

> 인테리어 수익성이 창호보다 높습니다.

허용:

> 영업실적 원장의 현장 기여마진율은 인테리어가 높지만, 내부 손익 기준 매출총이익률은 창호가 높습니다. 두 지표는 원가 포함범위와 매출 인식기준이 달라 별도로 판단해야 합니다.

AI는 예상 정산금을 실제 지급예정 확정금액처럼 표현하지 않는다.
