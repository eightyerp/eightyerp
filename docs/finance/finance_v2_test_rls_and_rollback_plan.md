# 2. RLS 권한 모델

## 2.1 역할

- `owner`
- `director`
- `admin`
- `manager`
- `employee`
- 직원 미연결 사용자
- 비활성 사용자
- 익명

## 2.2 관리자 범위

`owner`, `director`, `admin`만 다음 기능을 사용할 수 있다.

- 전체 수금·미수금·수금계획
- 전체 지출 승인·지급·분류
- 회사공통 비용
- 전체 직원 예상·확정 정산
- 재무 Excel 이관 승인
- 월마감
- 회사 손익
- 회사 목표 변경승인

## 2.3 직원 범위

일반 직원은 다음만 조회·등록한다.

- 본인 담당 고객·현장의 수금보고
- 본인이 등록한 지출요청
- 본인 담당 고객 현장 검색
- 본인의 예상 정산
- 본인의 확정 정산
- 본인의 지급내역

직원은 다음을 볼 수 없다.

- 타 직원 매출·마진·정산
- 회사 판관비
- 회사공통비
- 회사 전체 손익
- 전체 미수금
- 다른 직원 지출
- 재무 이관자료

## 2.4 View·RPC

- 신규 View는 `security_invoker=true`
- 모든 `SECURITY DEFINER` RPC는 `search_path=''`
- RPC 내부에서 `auth.uid`, `current_company_id`, `current_company_role`, `current_employee_id` 재검증
- 회사 ID를 클라이언트 입력값으로 신뢰하지 않음
- 직원의 대상 고객·계약·현장 접근권한을 RPC에서 재검사

# 4. 계산 자동테스트

## 4.1 수금

1. 계약금액 1억원, 기초수금 2천만원, ERP수금 3천만원이면 미수금 5천만원
2. 확정 전 수금은 계약 누계에 반영하지 않음
3. 직원 현금·카드 보고는 관리자 확인 전 `pending`
4. 계약금액 초과수금 차단 또는 명시적 초과수금 예외승인
5. 수금취소 후 누계 원복
6. 회차 배분합계가 수금액 초과 불가
7. 수금액은 매출에 더하지 않음

## 4.2 지출

1. 현장비는 현장 필수
2. 운영비는 현장 없음
3. 법인카드 사용은 지급상태 `paid`, 승인상태는 사용자 역할에 따라 결정
4. 계좌이체 요청은 승인 전 `unpaid`
5. 사업부 미분류는 손익 확정 반영 불가
6. 직접원가는 현장손익에 반영
7. 판관비는 사업부 또는 회사공통 손익에 반영
8. 증빙 미첨부는 지급상태와 별개로 보완업무함에 표시
9. 정산완료 현장 추가지출은 원현장 손익에 반영
10. 다음 정산 차감은 승인된 금액만 1회 적용

## 4.3 직원 정산

1. 인테리어 양의 마진 10,000,001원 → 5,000,000원 절사
2. 인테리어 음수마진 → 예상 기본정산 0원
3. 창호 계약 100,000,000원 → 2,000,000원
4. 공동매출 제외
5. 회사공통비 제외
6. 추가인센티브·차감·기지급 반영
7. 예상값 변경이 확정 배치 변경하지 않음
8. 확정 후 사후지출은 별도 조정 이벤트
9. 일반 직원은 본인 데이터만 조회

## 4.4 손익

```text
총매출 = 창호 + 인테리어
총직접원가 = 창호 + 인테리어
총판관비 = 창호 + 인테리어 + 회사공통
회사 영업이익 = 창호 영업손익 + 인테리어 영업손익 - 회사공통비
최종 순이익 = 회사 영업이익 + 기타수익 - 영업외·세금금융·기타조정
```

1원 이상 차이가 있으면 월마감·운영배포를 중단한다.

# 9. 롤백 전략

## 9.1 UI 롤백

- 이전 main SHA로 Vercel 재배포
- 신규 route는 feature flag로 비활성화
- 기존 수금·지출·정산 화면 유지

## 9.2 DB 롤백 원칙

컬럼·테이블을 즉시 DROP하지 않는다.

1. 신규 기능 쓰기 중단
2. 신규 원장 `is_active=false` 또는 상태 비활성화
3. 기존 legacy status·RPC로 화면 복귀
4. 신규 View 교체 또는 제거
5. 데이터 검증 후 별도 정리 migration

## 9.3 목표액 롤백

- 목표 변경 이력에 이전값 보존
- 활성 revision 전환으로 복구
- 직접 덮어쓰기 금지

## 9.4 지출 롤백

- 기존 `status` 유지로 레거시 화면 복귀 가능
- 신규 상태컬럼은 남겨도 기존 기능에 영향 없도록 구현
- 사업부 재분류는 이벤트 이력의 previous 값을 이용해 복구

## 9.5 정산 롤백

- 예상 정산 테이블만 비활성화
- 기존 확정·지급 배치는 변경하지 않음
- 직원 화면에서 잠정카드 숨김

## 9.6 수금 롤백

- 수금계획·기초잔액 기능 비활성화
- 기존 `collection_receipts`만 사용
- 이관 배치의 적용행 비활성화
